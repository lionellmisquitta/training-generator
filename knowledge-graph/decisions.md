# Decisions and direction (2026-10-25)

- **User direction:** Save the Training Generator Skill and a knowledge graph to the `training-generator` GitHub repository.
- **Design direction:** Generate and checkpoint **one coherent module at a time** rather than full-course mass templating; leave remaining modules as planned.
- **Quality boundary:** Pass deterministic checks, perform independent adversarial review, repair defects and require human approval before publication.
- **Not yet implemented:** Automated Codex/Claude Code calls, persistent checkpoint transitions, LMS/SCORM exports, knowledge-source ingestion.
- **Do not promote ideas as completed implementation.**
