# Adversarial pre-completion review

Before calling a lesson complete, the author must run an adversarial falsification pass. Same-model review is self-verification, NOT independent review.

1. Challenge syllabus alignment, objective coverage and prerequisites.
2. Independently solve all questions, recompute maths, run code and edge-case tests when possible.
3. Challenge pedagogy, age suitability, visuals and topic-specific manipulatives.
4. Validate cross-lesson originality against all prior authored lessons using n-gram and structural checks.
5. Render the offline player; mark browser behavior unverified if not executed.
6. Verify referenced facts with primary sources when available; distinguish URL syntax from actual validation.
7. Repair and retest, at most three cycles before reporting blockers.

Store self-review evidence tied to the submitted artifact SHA, with each test result marked pass, fail or not_executed. Chat may deliver a SELF-VERIFIED DRAFT, never an independently reviewed/approved lesson based solely on self-review. In Codex/VS Code, invoke Claude Code as an external reviewer only when actually authenticated and available. Keep the external checkpoint gate unchanged. Never fabricate reviewer evidence.
