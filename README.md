# Training Generator

[![Watch Training Generator demo](media/training-generator.gif)](media/training-generator-burst-graph-arrow.mp4)

**One prompt in. A whole course out.**

Create detailed, interactive lessons and offline HTML5 courses with examples, quizzes, checks and resumable module checkpoints.

## Install in your AI assistant

| I use… | Start here |
|---|---|
| **ChatGPT** | **[Download and install for ChatGPT](for-chatgpt/README.md)** |
| **Claude / Claude Code** | **[Download and install for Claude](for-claude/README.md)** |

Each installer folder provides a single `skill.zip` plus short steps. ZIPs are generated by GitHub Actions from the canonical `training-generator/` source; if no ZIP appears yet, packaging has not succeeded.
