# Install in ChatGPT

**Download:** [Training Generator skill.zip](skill.zip) (appears here after the packaging workflow completes).

1. Download `skill.zip` from this folder.
2. In ChatGPT, open the custom Skills manager (where enabled for your account).
3. Choose upload/import, select the ZIP and save.
4. Ask: **"Use Training Generator to design a course on [topic] for [audience]. Create and review only the first module."**

This ZIP should contain a single `training-generator/` folder, with `SKILL.md`, `agents/`, `references/` and `scripts/`. If the ZIP link is missing, the packaging workflow has not completed; do not mistake this README for an installed Skill.
